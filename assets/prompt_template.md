# Template prompt makalah (tanpa skill)

Salin, isi bagian [ ... ], lalu kirim ke Claude. Bila skill makalah-universal sudah terpasang, cukup tulis bagian "Data makalah" saja.

---

Buatkan makalah dalam format .docx dengan ketentuan berikut.

**Sebelum mulai**
- Tanya dulu: makalah individu atau kelompok? Bila kelompok, berapa jumlah anggota?
- Tanya universitas, fakultas, dan program studi. Format dokumen disesuaikan: bila ada format prodi tersebut, pakai itu; bila tidak, pakai format umum perguruan tinggi Indonesia (A4, margin 4-3-3-3 cm, Times New Roman 12, spasi 1,5, rata kiri-kanan, daftar pustaka APA 7). Utamakan format Universitas Riau bila kampusnya UNRI.

**Format**
- Kertas A4. Margin, spasi, dan ukuran font mengikuti format terpilih (bawaan: Times New Roman 12, spasi 1,5, rata kiri-kanan).
- Urutan: cover, daftar isi (otomatis), kata pengantar, Bab I Pendahuluan, Bab II Pembahasan, Bab III Penutup, daftar pustaka.
- Cover: judul makalah, logo kampus (bila ada), "Disusun untuk memenuhi tugas mata kuliah [mata kuliah]", "Dosen Pengampu: [nama dosen]", "Disusun oleh:" diikuti tabel identitas. Untuk kelompok: tabel dengan nomor, nama anggota 1..n, dan NIM. Untuk individu: satu baris "Nama Mahasiswa" dan NIM. Lalu baris institusi (fakultas/prodi/universitas) sesuai format terpilih, dan tahun.
- Cover dihitung sebagai halaman i tetapi nomornya disembunyikan. Daftar isi dan kata pengantar bernomor romawi di tengah bawah. Bab I dst bernomor angka mulai 1 di kanan bawah. Daftar pustaka tanpa nomor yang terlihat.
- Penomoran heading 1.1, 1.2, 2.1, dan seterusnya. Paragraf di bawah subbab sejajar dengan tulisan subbab (bukan angkanya), baris pertama tetap menjorok.
- Daftar pustaka gaya APA 7, urut abjad, menggantung dan rata kiri-kanan.
- Rumus memakai equation Word (rapi), bukan teks biasa. Hindari tabel; satu tabel boleh bila perlu.

**Isi**
- Kata pengantar standar. Bab I berisi latar belakang, rumusan masalah, tujuan, manfaat. Bab III berisi kesimpulan dan saran, tanpa sitasi.
- Bab II memakai kutipan (parafrase) dari referensi di setiap subbab, ditambah contoh bila ada. Contoh rekaan diberi label.
- Studi kasus (bila ada): tanpa sitasi dan tanpa referensi, tidak masuk latar belakang, rumusan masalah, dan tujuan.
- Daftar pustaka dengan link DOI atau open access yang valid. Hanya sumber yang benar-benar terverifikasi. Kalau ada sumber yang tidak bisa dibuka atau tidak relevan, jangan dipakai dan beri tahu alasannya.
- Bahasa baku dan natural, tanpa tanda pisah panjang, tanpa gaya kalimat khas AI.

**Data makalah**
- Jenis: [individu / kelompok]
- Jumlah anggota: [ ... ] (bila kelompok)
- Universitas: [ ... ]
- Fakultas: [ ... ]
- Program studi: [ ... ]
- Judul: [ ... ]
- Mata kuliah: [ ... ]
- Dosen pengampu: [ ... ]
- Materi / poin bahasan:
  - [ ... ]
  - [ ... ]
- Referensi: jumlah [ ... ], terbit [ ... ] tahun terakhir, minimal [ ... ] berbahasa Indonesia
- Referensi dari saya (boleh ditambah yang valid):
  - [DOI / link / PDF yang saya unggah]
- Studi kasus: [ada / tidak ada; bila ada, tema dan tingkat kesulitan]
